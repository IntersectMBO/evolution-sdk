# cryptography

## fromPrivateKey

Create a VKey from a PrivateKey (sync version that throws VKeyError).
For extended keys (64 bytes), uses CML-compatible Ed25519-BIP32 algorithm.
For normal keys (32 bytes), uses standard Ed25519.

**Signature**

```ts
export declare const fromPrivateKey: (privateKey: PrivateKey.PrivateKey) => VKey
```

Added in v2.0.0

# schemas

## Hex

An Ed25519 verification key as hex (32 bytes).

Validated as well as branded: a 32-byte hex string, either case. {@link toHex} returns
this type, so the kind survives leaving the typed domain.

⚠️ Not the 64-byte BIP32 extended form: a verifier handed the extended form where this belongs
fails on every signature. See {@link Bip32PublicKey.Hex}.

**Signature**

```ts
export declare const Hex: Schema.brand<Schema.filter<typeof Schema.String>, "VKeyHex">
```

Added in v2.4.0

## VKey (class)

Schema for VKey representing a verification key.
vkey = bytes .size 32
Follows the Conway-era CDDL specification.
